# 🎮 Tic Tac Toe

A responsive two-player Tic Tac Toe game built using HTML, CSS, and JavaScript.

## ✨ Features

- Two-player gameplay
- Player X and Player O
- Automatic win detection
- Draw detection
- Scoreboard
- New Game button
- Reset Score button
- Winning-cell animation
- Responsive design
- Works on desktop and mobile
- No external libraries required

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
